## 데이터

- **파일명:** `scores_2026.csv`
- **출처:** 한국기술교육대학교 12주차 AI 협업 프로그래밍 실습 제공 자료
- **원본 크기:** 114행 5열
- **정제 후 크기:** 100행 5열
- **열 설명:**
  - `학번`: 학생 식별 번호
  - `이름`: 학생 이름
  - `반`: 학생의 소속 반
  - `과목`: 평가 과목
  - `점수`: 과목별 평가 점수(0~100점)

### 빈 칸 및 이상 데이터 처리 방법

점수가 비어 있는 행은 평균 계산에 필요한 점수 정보가 없으므로 삭제하였다. 임의의 점수를 입력하면 실제 결과가 왜곡될 수 있기 때문이다. 모든 열의 값이 완전히 같은 중복 행은 하나만 남겼으며, 반과 과목의 앞뒤 공백을 제거하였다. 점수가 0점 미만이거나 100점을 초과하는 행도 유효한 점수 범위가 아니므로 삭제하였다.

정제 결과 원본 114행에서 총 14행이 제외되어 최종 100행이 남았다.
