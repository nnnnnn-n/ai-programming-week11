# 성적 CSV 검증 프로그램

## ① 무엇을 하나요 (What)
CSV 파일에서 성적 데이터를 읽고, 명세에 맞는 행은 유효한 점수 목록으로 반환하며 잘못된 행은 건너뛴 기록으로 남깁니다.

## ② 왜 만들었나요 (Why)
성적 CSV에는 빈 칸, 잘못된 점수, 열이 추가된 행처럼 정해진 형식에 맞지 않는 데이터가 섞일 수 있습니다. 이런 데이터를 구분하지 않고 읽으면 결과가 잘못되거나 프로그램 실행에 문제가 생길 수 있으므로, 유효한 데이터와 제외된 데이터를 구분하는 프로그램이 필요합니다.

## ③ 어떻게 쓰나요 (How)
Python 3가 설치되어 있는 환경에서 저장소 폴더로 이동해 실행합니다.

```bash
python load_scores.py scores.csv
```

## ④ 어떻게 테스트하나요
pytest를 설치한 뒤 프로젝트 폴더에서 테스트를 실행합니다.

```bash
python -m pip install pytest pytest-cov
pytest
```

테스트 통과 화면은 실제 실행 후 여기에 캡처하거나 출력 내용을 붙입니다.

## ⑤ 파일 구성
| 파일 | 하는 일 |
|---|---|
| `load_scores.py` | 성적 CSV를 읽어 유효한 데이터와 제외 기록을 반환합니다. |
| `test_load_scores.py` | 정상, 예외, 빈 줄, 쉼표 포함 이름, 경계값 테스트를 실행합니다. |
| `scores.csv` | 기본 테스트용 성적 데이터입니다. |
| `empty.csv` | 헤더만 있는 파일 테스트용 데이터입니다. |
| `weird.csv` | 다양한 비정상 데이터 테스트용 파일입니다. |
| `bug3_logic.py` | 별도의 논리 오류 실습용 함수가 들어 있습니다. |
| `test_ai_A.py` | 코드 제공 방식으로 AI가 생성한 테스트입니다(실제 원본으로 교체 필요). |
| `test_ai_B.py` | 명세 제공 방식으로 AI가 생성한 테스트입니다(실제 원본으로 교체 필요). |
